# ניהול משימות – אזורים

אב-טיפוס mobile-first לניהול משימות ופרויקטים, בעברית וב-RTL.

## הפעלה

```bash
npm install
npm run dev
```

## גרסת MVP ראשונה
- מסך היום שלי
- משימות לפי פרויקט ומועד
- הוספה מהירה של משימה
- מסך פרויקטים
- מסך AI כהכנה ליכולות עתידיות

## המשך מתוכנן
דשבורד מלא לפרויקט, מסמכים, חילוץ משימות מסיכומי ישיבות, Microsoft Graph ל-Outlook, Cloudflare Workers/D1/R2 ושכבת AI.
