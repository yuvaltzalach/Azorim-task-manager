# ניהול משימות – אזורים

אב-טיפוס mobile-first לניהול משימות ופרויקטים, בעברית וב-RTL.

## הפעלה

```bash
npm install
npm run dev
```

## גרסת MVP ראשונה
- מסך היום שלי
- משימות לפי פרויקט ומועד
- הוספה מהירה של משימה
- מסך פרויקטים
- מסך AI כהכנה ליכולות עתידיות

## המשך מתוכנן
דשבורד מלא לפרויקט, מסמכים, חילוץ משימות מסיכומי ישיבות, Microsoft Graph ל-Outlook, Cloudflare Workers/D1/R2 ושכבת AI.


## Product status
The deployed MVP now includes RTL Hebrew UI, Azorim-inspired branding, local task persistence, project dashboards, task completion/deletion, due-date categories, project filtering, completed-task views, document/AI extraction placeholders, and automatic GitHub Pages deployment.

## Production roadmap
Real document upload/storage, server database, authentication, Microsoft Graph/Outlook, and live AI extraction require backend credentials and organizational approval. The UI intentionally keeps these as staged capabilities rather than pretending they are connected.
